# 🌐 Bikash Kumar Malik — Personal Portfolio

A modern, fluid-motion personal portfolio engineered with responsive glassmorphism, mouse-tracking spotlight effects, and interactive career timelines.

---

## ⚡ Features
* **Fluid Motion & Micro-Interactions:** CSS blob animations, mouse-tracking spotlight cards, scroll reveal observers, and smooth transitions.
* **100% Up to Date with Resume:**
  * **Bathroom Bubbles Ltd** (Customer Services Executive — Amazon Seller & Vendor Central Operations)
  * **31West Global Services** (Subject Matter Expert — Technical Support & SOP Leadership)
  * **Wipro Limited** (Associate — Healthcare Claims Adjudication & Siebel)
* **Featured Software Engineering:** Highlights **RetroFlux PRO** (Python/Tkinter, Flutter Android, FFmpeg, Gumroad Licensing API).
* **Direct Resume Download:** Integrated high-resolution PDF download (`Bikash_Kumar_Malik_Resume.pdf`).
* **1-Click Copy Interactions:** Fast toast notifications for copying email and phone number.
